04 / INTERACTIVE LAB

Run the checks yourself.

Four browser-based experiments. Real local assertions, illustrative data and explicit limitations. No external services, model calls or company systems.

QE / PLAYGROUNDLOCAL EXECUTION

Message contract validator

Validate a JSON object against illustrative Avro-like field rules, including a nullable union. This is not actual Avro serialization or a Kafka connection.

Release performance gate

Generate repeatable synthetic latency samples and evaluate p95 and error-rate thresholds. No real load is sent to a server.

API response assertion runner

Choose a fixture, edit the response and run checks on status, content type and response fields. Assertions execute locally against the provided JSON, not a live REST API.

AI response policy gate

Evaluate a fictional support response against a small set of deterministic rules: approved price, escalation, and no unsolicited collection of sensitive data. This is not an LLM judge or a compliance certification.
